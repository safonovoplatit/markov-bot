# Бот с пацанскими цитатами для Telegram

Бот читает текстовые сообщения из HTML-выгрузок Telegram, берёт подходящие фразы из выгрузки и соединяет фразы на общую тему. Генератор работает локально, ключ для языковой модели не нужен.

## Запуск

Нужен Python 3.10 или новее.

1. Создайте бота через BotFather. Для запросов через `@имя_бота` включите inline-режим через `/setinline`.
2. Добавьте бота в администраторы канала и дайте ему право публиковать сообщения.
3. Вставьте токен между кавычками в строке `BOT_TOKEN = ""` в начале `bot.py`. Если задана переменная окружения `BOT_TOKEN`, она имеет приоритет. Храните файл с заполненным токеном локально.
4. Установите зависимости и запустите бота.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export CHANNEL_ID='@имя_канала'
python bot.py
```

Для закрытого канала укажите числовой ID вида `-100…`. Чтобы узнать свой ID, напишите боту `/id` в личке. Затем перезапустите его с `ADMIN_IDS` — списком разрешённых ID через запятую.

```bash
export ADMIN_IDS='123456789'
python bot.py
```

Канал можно указать в `CHANNEL_ID` в начале `bot.py`. Одноимённая переменная окружения имеет приоритет. При заданном канале бот отправляет первую цитату при запуске, затем публикует каждые 200 секунд. Интервал задаётся в `POST_INTERVAL_SECONDS` в начале `bot.py`. Для автопубликации бот должен оставаться запущенным. Если публикация завершилась ошибкой, бот пишет причину в терминал и снова пробует на следующем интервале. История по умолчанию хранится в `data/posts.sqlite3`. Бот исключает из выбора последние 30 опубликованных цитат. Через `BOT_SIGNATURE` можно добавить подпись к постам.

## Команды в личке

- `/quote друзья` — получить черновик по теме. Без темы бот опирается на частоты в выгрузках.
- `/post` — опубликовать последний черновик или сгенерировать пост, если черновика нет.
- `/post дорога` — сгенерировать и сразу опубликовать цитату по теме.
- `/makeq [тема]` — создать новую цитату и сразу опубликовать её в канале. Тема необязательна.
- `/reload` — перечитать выгрузки. Команды `/post` и `/reload` доступны пользователям из `ADMIN_IDS`. Команда `/makeq` также доступна владельцу и администраторам настроенного канала.

## Смена выгрузки

По умолчанию бот читает все файлы `.html` и `.htm` рядом с `bot.py`. `messages.html` служит основным источником. Остальные файлы используются, если в основном нет подходящей фразы, например по заданной теме. Если `messages.html` отсутствует, бот использует остальные выгрузки. Чтобы перейти на другую выгрузку, задайте `CORPUS_DIR` с путём к папке, содержащей её HTML-файлы, и перезапустите бота. После замены файлов в этой же папке достаточно команды `/reload`. Для одного конкретного файла можно задать `BOOTSTRAP_HTML`, у него приоритет над папкой.

Поддерживается HTML-формат экспорта Telegram Desktop. Можно объединять несколько экспортов в одной папке. После замены файла фразы и словарь обновляются при `/reload` или перезапуске. Если во всех выгрузках нет текстовых сообщений, `/reload` сообщает об ошибке и сохраняет текущий генератор.
